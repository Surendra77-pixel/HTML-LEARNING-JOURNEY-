# href attribute Opening the Google Page

Using the href attribute in an anchor tag

Click here to go to Google

In this example, we have an anchor tag <a> with the href attribute set to "https://www.google.com". When a user clicks on the link, they will be directed to the Google homepage.

in this example, the <a> element is used to create a hyperlink. The href attribute specifies the URL of the page the link goes to. In this case, the link will take the user to "https://www.google.com".
