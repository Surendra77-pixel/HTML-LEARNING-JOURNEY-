Using the lang attribute

Specifying the language of a document with the lang attribute

The lang attribute is used to specify the language of the content in an HTML document. This information can be useful for search engines, screen readers, and other tools that process web content.

In this example, we have set the lang attribute to "en" in the opening <html> tag, indicating that the content of the document is in English. You can change this value to specify different languages, such as "fr" for French or "es" for Spanish.
