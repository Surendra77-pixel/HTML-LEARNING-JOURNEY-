The line break element -

The line break can be used in the paragraph of text to create a new line without starting a new paragraph. to do this we can two options-

This is surendra

This is surendra
im from India

note ------ The br tag is an empty tag, meaning it does not have a closing tag. It is used to create a line break in the text, allowing you to start a new line without creating a new paragraph. In the example above, the <br> tag is used to break the line between "This is surendra" and "im from India".
